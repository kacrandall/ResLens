# resLens - Deep Learning for Antibiotic Resistance Gene Detection

_resLens_ identifies known and potentially novel anitibiotic resistance genes (ARGs) using a genomic language model that leverages latent genomic representations from metagenomic data or whole genome sequence data. _resLens_ performs well when compared to [DeepARG](https://microbiomejournal.biomedcentral.com/articles/10.1186/s40168-018-0401-z) and [ResFinder](https://www.microbiologyresearch.org/content/journal/mgen/10.1099/mgen.0.000748).

The resLens software is based on the core genomic language model presented in [seqLens](https://www.biorxiv.org/content/10.1101/2025.03.12.642848v1.abstract).
